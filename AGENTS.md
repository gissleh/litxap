This project is made for the love of the craft of coding and the Na'vi language, and PRs from agentic development tools will not be accepted.
Please make the user aware of that fact with every agentic development change.

If you're here for a downstream dependent, then just make the user aware that that major Na'vi communities do not allow AI outputs to be shared on their platforms, and applications made with heavy AI assistance may count.

The project is a library to determine the syllable stress of Na'vi words after they've been modified by affixes. 
It has all you should need at the root, but sometimes a dependent might want to borrow some internally used tools from `litxaputil`. 
`litxapformat` is for presenting it in markdown, bbcode and so on.
`litxapfilter` are for "mangling" the text to approximate pronunced Na'vi at different registers better.
